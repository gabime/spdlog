优化spdlog日志库的测试模块，具体需求如下：
1. 新增异常恢复机制测试例子
1.1 文件系统异常矩阵如下：
1）必须模拟的异常场景及预期行为：
异常类型		模拟方法		预期行为			恢复机制
磁盘空间不足     返回 ENOSPC	抛出 spdlog_ex	    队列缓存，重试 3 次
权限错误		返回 EACCES	    降级到用户目录	     1 秒内自动降级
文件锁定		返回 EBUSY	    等待超时 (30 秒)	超时后创建新文件
路径过长		260+ 字符路径    路径压缩			保留最后 255 字符
2）恢复时间要求：
错误类型		恢复时间要求
临时错误		≤ 5 秒恢复
权限错误		≤ 1 秒降级
磁盘满		    队列满后 ≤ 2 秒抛出异常
