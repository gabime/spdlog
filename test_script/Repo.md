spdlog 是一个专为 C++11 及以上环境设计的高性能、轻量化、仅头文件的开源日志库，是目前 C++ 生态系统中最主流的日志工具。该库旨在为 C++ 开发者提供高效、易用的日志记录解决方案，解决传统日志库性能低下、依赖复杂、集成困难等问题。

spdlog 采用纯头文件设计，零依赖且易于集成，项目中直接 #include 即可使用。核心特性包括极致高性能（比 glog、log4cpp 等快得多）、跨平台兼容性（完美支持 Windows、Linux、macOS 等主流系统）、丰富的格式化功能（基于 fmt 库）、异步日志模式（不阻塞业务线程）、多线程安全、多种日志目标（控制台、文件、syslog 等）以及灵活的日志级别控制。

技术栈基于 C++11/14/17 标准，支持同步/异步日志引擎，内置 8 个日志级别，提供旋转文件、每日文件等高级功能。该库采用 MIT 开源协议，完全免费商用，无版权风险，已成为 C++ 社区事实上的标准日志解决方案。
